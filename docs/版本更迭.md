# Loop 版本更迭

## v0.1 文档与对话

项目选择、结构化问题深究、五份核心 Markdown、编辑/哈希/批准门禁、基础 SQLite 事件记录和三视图工作台。

## v0.2 单 Agent 执行

OpenAI/DeepSeek 适配、文件与命令工具、分级审批、预算、SSE 和失败恢复。

## v0.3 多 Agent

任务树、并发调度、Git worktree、子 Agent 结果文档、Lead Main 集成和全局验证。

## v0.4 可靠恢复

Markdown 检查点、顺序 Main 换代、并行模块 Main、租约、事件重放和幂等恢复。

## v0.5 安全与自动化

全自动模式、硬安全线、junction/符号链接防逃逸、Windows 凭据管理器和完整审计。

## v1.0 稳定版

完成性能、安全和恢复测试；稳定三种 UI；提供安装、升级、数据迁移和故障排查文档。

## 兼容与迁移

- SQLite schema 使用单调递增版本和事务迁移，不自动降级。
- Markdown front matter 的 `loop_schema` 独立于应用版本；旧 schema 先转换草稿，用户确认后批准。
- Provider 模型 ID 始终由用户配置，升级应用不静默更换模型。
- 后续版本再开放图片输入、跨平台桌面封装、远程执行、多用户和更多供应商。
