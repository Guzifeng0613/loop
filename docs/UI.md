# Loop UI

## 视觉系统

界面采用真白与冷浅灰背景、深墨文字和克制蓝紫强调色。字体优先使用 `Inter`、`Segoe UI` 和系统无衬线。信息层级依靠字号、字重、细边框和留白，不使用装饰性渐变、发光或无意义卡片。

核心 token：背景 `#f5f6f8`、表面 `#ffffff`、主要文字 `#17191f`、次要文字 `#69707d`、边框 `#e3e6ec`、强调 `#5b5bd6`、成功 `#21875b`、警告 `#8b4d0d`、危险 `#c44747`。圆角以 8/12/16px 为主，交互动画 140–220ms，并尊重 `prefers-reduced-motion`。

## App Shell

- 左侧 72px 导航轨包含 Loop 标识、工作台、流程、IDE、设置按钮。
- 次级侧栏展示项目、运行列表和当前文档门禁。
- 顶栏展示当前运行、状态、模型模式、预算和暂停/继续操作。
- 活动抽屉展示最近事件、命令输出、审批、恢复提示和实际预算消耗。
- 活动入口展示 `connecting/live/reconnecting/offline`，工具输出事件直接增量到达，不再逐事件刷新完整工作台。

## 工作台视图

默认三栏：左侧运行上下文，中间澄清对话，右侧文档/任务/审批检查器。对话使用结构化理解卡，不把所有内容压成普通气泡。输入区支持多行文本和发送快捷键；图片入口首版隐藏。

## 流程视图

以理解、规范、计划、执行、验收五个阶段构成时间轴。`paused`、`failed`、`cancelled` 使用 `previousState` 叠加在实际中断阶段；无运行时展示 onboarding。验收阶段只在当前运行的交付摘要加载成功后开放决定，展示文件、提交、任务结果、验证、费用、风险和未解决项；合并决定随后进入一次性审批。

## IDE 视图

左侧文件树，中间 Markdown 编辑器和保存前 diff，右侧 Agent/任务树，底部为真实运行事件。Bootstrap 只带文档 metadata，进入或切换文档时按需加载正文，加载完成前锁定编辑。未保存内容按项目与 `docId` 写入本机草稿，切文档/切视图不会丢失；服务器 hash 变化时进入冲突态而非覆盖，关闭页面前触发保护，行号与编辑器同步滚动。diff 折叠长段未变化内容并保留新旧行号。

## 运行与设置

- 新建运行在固定/自动模式间切换；自动模式分别选择 Lead 模型和子任务允许供应商。
- 顶栏预算摘要显示调用次数，更多菜单提供导出、失败重试和取消；破坏性取消需要二次确认。
- 设置页可编辑 Agent 并发/总量/深度/直属上限和模型调用、输入 token、输出 token、运行时长预算。
- 审批卡同时提供拒绝、批准一次和当前运行内批准同类三种动作。
- 审批卡展示风险、`ruleKey`、能力和资源范围；不可复用能力禁用“批准同类”。

## 状态与响应式

- 加载、空状态、断线、失败、预算暂停、文档过期和审批等待均有明确恢复操作。
- 低于 980px 自动进入流程视图；侧栏和检查器改为抽屉。
- 所有按钮、标签页、树节点和输入具有键盘焦点、ARIA 名称和不少于 40px 的主要点击区域。

## UI 优化方向

1. P0：补齐 `ACTION_OUTCOME_UNKNOWN`、Git 冲突和基线漂移的专用恢复页面。
2. P1：为长事件流和超长 diff 引入窗口化虚拟列表；当前先使用有界快照与 `content-visibility`。
3. P1：IDE 窄屏增加文件树与 Agent 检查器抽屉；事件终端支持筛选、复制和完整输出详情。
4. P1：完成所有对话框的焦点圈定/恢复，并引入自动化 axe/WCAG 回归。
5. P2：为真实大任务增加任务依赖图缩放、键盘导航和无动画替代视图。
