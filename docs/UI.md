# Loop UI

## 视觉系统

界面采用真白与冷浅灰背景、深墨文字和克制蓝紫强调色。字体优先使用 `Inter`、`Segoe UI` 和系统无衬线。信息层级依靠字号、字重、细边框和留白，不使用装饰性渐变、发光或无意义卡片。

核心 token：背景 `#f5f6f8`、表面 `#ffffff`、主要文字 `#17191f`、次要文字 `#69707d`、边框 `#e3e6ec`、强调 `#5b5bd6`、成功 `#21875b`、警告 `#b56a16`、危险 `#c44747`。圆角以 8/12/16px 为主，交互动画 140–220ms，并尊重 `prefers-reduced-motion`。

## App Shell

- 左侧 72px 导航轨包含 Loop 标识、工作台、流程、IDE、设置按钮。
- 次级侧栏展示项目、运行列表和当前文档门禁。
- 顶栏展示当前运行、状态、模型模式、预算和暂停/继续操作。
- 底部活动抽屉展示事件、命令输出、审批和恢复提示。

## 工作台视图

默认三栏：左侧运行上下文，中间澄清对话，右侧文档/任务/审批检查器。对话使用结构化理解卡，不把所有内容压成普通气泡。输入区支持多行文本和发送快捷键；图片入口首版隐藏。

## 流程视图

以理解、规范、计划、执行、验收五个阶段构成时间轴。当前阶段展示质量门槛、待办和主操作；已完成阶段可回看，未满足依赖的阶段不可跳过。

## IDE 视图

左侧文件树，中间 Markdown 编辑器和 diff，右侧 Agent/任务树，底部为终端与事件。所有面板共享当前运行状态，不复制业务数据。

## 状态与响应式

- 加载、空状态、断线、失败、预算暂停、文档过期和审批等待均有明确恢复操作。
- 低于 980px 自动进入流程视图；侧栏和检查器改为抽屉。
- 所有按钮、标签页、树节点和输入具有键盘焦点、ARIA 名称和不少于 40px 的主要点击区域。
